# Memex v1.2.0

本次更新加入完整的 AI 周报模块。

## 新增

- 独立「周报」一级模块，沿用三栏工作台
- 最近 7 个自然日默认周期，按任务时间字段筛选候选任务
- 已完成 / 进行中 / 待办分组，全选、分组选择和逐项选择
- 关联笔记可选发送，默认关闭
- 结构化周报模板：基础提示词、有序章节、自定义约束
- 内置模板只读，可复制后编辑；自定义模板支持复制、编辑和删除
- OpenAI 兼容 Chat Completions 模型生成 Markdown 周报
- 历史报告保存生成时的任务、笔记和模板快照
- Markdown 编辑、安全预览和 500ms 自动保存
- Markdown 与 PDF 导出
- 「重新生成」预填原周期、模板、笔记选项和可匹配的任务
- 设置中新增 AI 服务配置、连接测试和可调超时时间

## 安全与隐私

- API Key 使用 Electron `safeStorage` 加密保存
- 渲染进程只能读取 `hasApiKey`，不能读取完整 Key
- 生成前显示目标服务地址和发送数量
- 固定系统规则位于 `system` 消息，用户模板和数据位于 `user` 消息
- Markdown/PDF 渲染禁用原始 HTML
- JSON 导出包含周报与模板，但不包含 AI 配置或密钥

## 数据兼容

- 数据库迁移升级到版本 2
- 不修改或删除现有任务、笔记、标签和设置
- 新增加载已有 v1 数据的迁移回归测试
