# Memex v1.1.14

本次更新集中修复自动更新链路。

## 本版修复

- **静默安装后自动重开应用**：assisted 安装包（`oneClick: false`）在静默安装时需要 `--force-run` 才会启动应用，之前更新完成后应用保持关闭
- **下载中断后从断点续传**：失败时先把已接收数据落盘，下次重试从断点继续，不再从头下载 95 MB
- **下载空闲超时**：长时间收不到数据会自动中断并重试，不会永久卡住
- **测试稳定性**：把依赖计时器的断线测试改为确定性的响应截断，修复 CI 偶发失败

## 自动更新行为

点击「设置 → 软件更新 → 一键更新」后：

1. 从 GitHub Releases 检查最新版本（不调用 API，无 60 次/小时限制）
2. 下载安装包，支持断点续传
3. 用 `latest.yml` 的 sha512 或 GitHub 资产 digest 的 sha256 校验
4. 启动器接管：关闭应用 → 静默安装 → 自动重新打开

## 网络说明

更新下载走 Electron `net.fetch`（Chromium 网络栈），会遵循 Windows 系统代理、PAC 与 VPN 路由。
