# Memex v1.0.1

本地优先的任务清单与富文本笔记桌面应用，内置只读 MCP，让 AI 客户端可以读取你的任务；笔记访问需在应用设置中手动开启。

## 本版修复

- **任务详情属性区支持折叠**：标题和描述保持常驻，状态 / 优先级 / 截止时间 / 标签 / 关联笔记收进可折叠属性区
- 折叠时显示一行摘要，例如「待办 · 中 · 工作」，不用展开也能看到关键信息
- 展开 / 收起带高度过渡动画，折叠状态会记住，下次打开保持上次选择
- 修复 E2E 测试与正在运行的应用实例发生单实例锁冲突的问题（测试改用独立 userData 目录）

## 完整功能

### 任务

- 三态任务：待办 / 进行中 / 已完成
- 优先级：高 / 中 / 低
- 截止时间与逾期提示
- 标签、描述、关联笔记
- 智能视图：收件箱、今天、即将到期、已完成、回收站
- 软删除、恢复、彻底删除；回收站保留 30 天

### 笔记

- TipTap 富文本编辑器：标题、列表、任务清单、引用、代码
- 停止输入 500ms 自动保存，失焦时强制保存
- 标题从正文首行自动派生
- 标签、置顶、回收站
- 正文以 ProseMirror JSON 保存，同时生成纯文本供搜索与 AI 读取

### 搜索与快速记录

- `Ctrl+K` 统一搜索任务和笔记，支持中文
- `Ctrl+Shift+Space` 打开独立快速记录小窗
- 快速记录默认任务，`Ctrl+2` 切换任务 / 笔记
- `Enter` 保存并关闭，`Ctrl+Enter` 保存并继续，`Esc` 关闭

### 界面

- 三栏布局：导航 / 列表 / 详情
- 侧栏和列表均可折叠
- 亮色、深色、跟随系统三种主题
- 空状态、加载骨架、过渡动效
- 托盘、单实例、关闭到托盘、开机自启

### 数据安全

- SQLite 本地存储，WAL 模式
- 数据默认位于 `%APPDATA%\Memex\memex.db`
- 每日自动备份，保留最近 7 份
- 支持手动立即备份
- 支持 JSON 全量导出
- 应用本身不发起任何网络请求

### MCP

- 通过 stdio 提供只读 MCP server
- 默认只暴露任务工具：
  - `list_tasks`
  - `search_tasks`
  - `get_task`
- 在设置中开启“任务 + 笔记”后，额外提供：
  - `list_notes`
  - `search_notes`
  - `get_note`
- 权限切换实时生效，无需重启 AI 客户端
- `tools/list` 与 `tools/call` 双层校验
- 不提供任何写入工具
- 设置页可一键复制 MCP 配置

## 安装

1. 下载并运行 `Memex Setup 1.0.1.exe`
2. 按向导选择安装位置
3. 首次启动后数据目录会自动创建

安装包 SHA-256：

```text
F884EE08F55EDA4CA6D6B46745D2529A841F84A769942C2C6CB37299E5285A2D
```

## 配置 MCP

1. 打开 Memex 设置
2. 找到「AI 访问权限」
3. 选择「仅任务」或「任务 + 笔记」
4. 点击「复制 MCP 配置」
5. 粘贴到 Claude Desktop / Codex 等客户端的 MCP 配置中

生成的配置类似：

```json
{
  "mcpServers": {
    "memex": {
      "command": "C:\\Program Files\\Memex\\Memex.exe",
      "args": ["C:\\Program Files\\Memex\\resources\\mcp\\index.mjs"],
      "env": {
        "ELECTRON_RUN_AS_NODE": "1",
        "MEMEX_DB_PATH": "C:\\Users\\<user>\\AppData\\Roaming\\Memex\\memex.db"
      }
    }
  }
}
```

`ELECTRON_RUN_AS_NODE=1` 让 MCP 使用 Electron 内置的 Node 运行时，与主应用共用同一套 SQLite，避免原生模块 ABI 问题。

## 隐私说明

- 数据默认只保存在本机
- 选择「仅任务」时，AI 只能读取任务
- 切换到「任务 + 笔记」后，笔记全文会进入 AI 客户端上下文，等同于发送给对应的模型服务商
- 是否开启由你决定，默认关闭笔记访问

## 已知限制

- 当前仅提供 Windows x64 安装包
- 安装包未配置商业代码签名证书，首次安装可能出现 SmartScreen 提示
- MCP 当前为只读，不支持通过 AI 创建或修改任务
- 暂不支持图片 / 附件、子任务、重复任务、文件夹、Markdown 导出
- SQLite 驱动使用 Node 22 内置 `node:sqlite`，该 API 在 Node 22 中仍标记为 experimental；本项目已验证 FTS5、备份和只读连接

| --- | --- |
| `Ctrl+K` | 统一搜索 |
| `Ctrl+N` | 新建任务 / 笔记 |

| `Ctrl+2` | 快速记录中切换任务 / 笔记 |
