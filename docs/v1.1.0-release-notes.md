# Memex v1.1.0

本次更新加入应用内自动更新，并把更新源切换为 GitHub Releases。

## 新增：自动更新

打开「设置 → 软件更新」：

- 点击「检查更新」读取 GitHub 上的最新 Release
- 发现新版本后显示版本号、发布说明和大小
- 点击「一键更新」下载安装包
- 下载完成后自动校验、静默安装并重启

### 校验机制

更新器使用两种校验来源，至少一个存在才允许安装：

1. Release 中的 `latest.yml`（sha512，electron-builder 生成）
2. GitHub Release 资产自带的 `digest`（sha256，GitHub 服务端计算）

校验失败会删除已下载文件并中止安装，不会执行未通过校验的安装包。

### 网络与限流

- 只访问 `api.github.com` 和 GitHub Release 下载域名
- GitHub 未认证 API 限额为每小时 60 次，手动检查完全够用
- 触发限流时提示剩余等待时间，不会静默失败

## 其他变化

- 安装包文件名统一为 `Memex-Setup-<version>.exe`，与 `latest.yml` 保持一致
- 支持 `MEMEX_UPDATE_OWNER` / `MEMEX_UPDATE_REPO` 覆盖更新仓库
- 支持 `MEMEX_USER_DATA` 覆盖用户数据目录，便于测试和隔离环境
- 修复 TipTap 编辑器内 `Ctrl+K` 被编辑器拦截的问题

## 配置 MCP

1. 打开 Memex 设置
2. 找到「AI 访问权限」
3. 选择「仅任务」或「任务 + 笔记」
4. 点击「复制 MCP 配置」
5. 粘贴到 Claude Desktop / Codex 等客户端的 MCP 配置中

## 隐私说明

- 数据只保存在本机
- 应用只在检查更新和下载更新时访问 GitHub
- MCP 默认只读任务，笔记访问需手动开启
- MCP 不提供任何写入工具

## 已知限制

- 当前仅提供 Windows x64 安装包
- 安装包未配置商业代码签名证书，首次安装可能出现 SmartScreen 提示
- GitHub API 未认证限额为 60 次/小时
- MCP 当前为只读
- 暂不支持图片 / 附件、子任务、重复任务、文件夹、Markdown 导出
- SQLite 驱动使用 Node 22 内置 `node:sqlite`，该 API 在 Node 22 中仍标记为 experimental

## 技术信息

- Electron 39.8.10（内置 Node 22.22.1）
- React 19 + TypeScript 5.9 + electron-vite 6
- Tailwind CSS 4 + shadcn/ui 风格组件 + motion
- TipTap 3
- Node 22 内置 `node:sqlite`，WAL + FTS5 trigram
- `@modelcontextprotocol/sdk` + stdio
- pnpm workspace + Vitest + Playwright
